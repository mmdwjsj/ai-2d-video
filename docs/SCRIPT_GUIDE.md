# 剧本编写规范

工作台「制作 · 第 3 段 剧本」有同一份规范的精简版，可直接点「填入规范示例」把示例填进输入框。本文是完整说明。

## 1. 先定语言类型

项目语言类型在**新建项目时选择**（项目首页），也可在**页面顶部随时切换**，取值只有三个：

| 语言类型 | 剧本编辑框 | 配音 / 字幕 | 成片版本 |
| --- | --- | --- | --- |
| 中文 | 只有中文 | 只做中文 | 中文版 MP4 |
| 泰语 | 只有泰语 | 只做泰语 | 泰语版 MP4 |
| 双语（中＋泰） | 中泰双栏 | 双语 | 双语版 MP4 |

单语项目不会生成另一种语言的台词（对应字段留空）。切换语言类型**只改变显示与导出目标**，已经写好的另一种语言内容仍保留在 `data/projects/<id>/script.json` 里，切回「双语」即可看到。

## 2. 一行一句

剧本按**行**切分，每行对应一个镜头、一句台词。不要把整段小说或散文粘进来。

三种行的写法：

```text
【场景】曼谷街边餐馆 · 傍晚 · 暖光
旁白：下班后的曼谷，最热闹的时候才刚开始。
妮娜微笑地说：“你好，需要吃点什么吗？”
```

| 行类型 | 格式 | 作用 |
| --- | --- | --- |
| 场景行 | `【场景】场景名 · 时间 · 光线` | 只提取场景名并下发给每行，**不生成对白行、不占镜头**（泰语写 `ฉาก:`） |
| 情境 / 旁白行 | `旁白：一句话` | 交代**当时情况和人物心情**的说明，不是人物台词：不进说话人下拉、不设情绪动作，成片里作画外音字幕（泰语写 `บรรยาย:`） |
| 对白行 | `人物名＋表情/动作＋说：“台词”` | 拆成 说话人 / 台词 / 情绪 / 动作 四列，分镜据此出场与画表情 |

粘贴或导入文案时**一律按这一套规则解析**，不做「这是哪种剧本风格」的自动判别：认不出的人名留空让用户选，认不出的描述给中性默认值，不会静默换一套解释方式。

## 3. 一句对白必须包含的内容

```text
妮娜认真地说：“阿顿，交给你一个重要任务，看好吨吨！”
```

生成后拆成对白行的四列：

| 对白行列 | 值 | 来源 / 用途 |
| --- | --- | --- |
| 说话人 | 妮娜 | 冒号前的人名，匹配「制作 · 人物」段里的人物，决定参考图与音色 |
| 中文对白 | 阿顿，交给你一个重要任务，看好吨吨！ | 只取引号内的**纯台词**，写进字幕、配音并决定时长 |
| 情绪 | 认真 | 从描述段「认真地」自动匹配，写进镜头 `expression` |
| 动作 | 正视对方 | 由描述段推导，写进镜头 `action` |

人物名、`地说`、`【场景】` 这些说明性前缀**不会混进台词列**（以前整行原文塞进 `textZh`，字幕会把「妮娜认真地说」一起念出来）。

情绪与动作是确定性词表映射：`认真 → 认真 / 正视对方`、`皱眉 → 不满 / 皱眉`、`慌张 → 慌张 / 摆手`、`冷笑 → 不屑 / 抱臂`；认不出的描述给「自然 / 自然对话」。生成后每一行都能**下拉选常用词，也能直接打字自己填**，词表不满足就写自定义的；自定义值会并入该行候选项。渲染层按情绪画不同眉眼与嘴型（笑、皱眉、慌张、冷笑、认真等），选了画面会跟着变。

场景、时间、光线放在场景行里，不塞进台词。

## 4. 完整示例（中文）

```text
【场景】家里客厅 · 白天 · 自然光
旁白：本以为是轻松带娃任务
妮娜认真地说：“阿顿，交给你一个重要任务，看好吨吨！”
阿顿自信地说：“放心！包在我身上！”
吨吨兴奋地说：“爸爸，你看我画的恐龙！”
旁白：转头直接暴击
妮娜皱眉说：“墙上怎么画成这样？”
阿顿慌张地说：“是我画的！别骂孩子！”
妮娜冷笑地说：“行，那今晚你来擦墙。”
旁白：父爱，代价是擦墙
```

结构：开头旁白 → 3 轮对话 → 收尾旁白。共 10 行，其中【场景】行只作场景提示，解析出 **9 行**（5 行人物对白 + 4 行情境/旁白），提交分镜后就是 9 个镜头；4 行旁白是情境说明，不指定人物，画面是场景空镜 + 画外音字幕，也不署名说话人。

## 5. 完整示例（泰语，日常口语）

```text
ฉาก: ร้านอาหารข้างถนนกรุงเทพฯ · เย็น · แสงอุ่น
บรรยาย: เลิกงานแล้ว ตลาดเพิ่งเริ่มคึกคัก
นีน่ายิ้มแล้วถามว่า “สวัสดีค่ะ จะรับอะไรดีคะ”
อาร์ตถามอย่างสงสัยว่า “วันนี้ยังมีต้มยำไหมครับ”
ลุงสงชัยตอบอย่างอารมณ์ดีว่า “เพิ่งต้มเสร็จเลย นั่งก่อนลูก”
นีน่าบอกอย่างดีใจว่า “งั้นเอาสองที่นะคะ ใส่กะทิเพิ่มหน่อย”
บรรยาย: ซุปชามร้อน ๆ คือวิธีปิดวันที่ดีที่สุด
```

泰语要写泰国人日常真会说的句子，**不要把中文逐字硬译**。本地规则 Provider 生成的是口语句式模板，正式出片前仍需人工校对；阶段二接了文本模型可以重写。

## 6. 硬性约束

- 一句台词 ≤ 25 个汉字（泰语 ≤ 35 字符），9:16 竖屏字幕才不会挤成三行。
- 一行只写一个人说的一句话。
- 人物名必须是项目里已有的人物（默认妮娜 / 阿顿 / 吨吨，可在「制作 · 人物」段自由增删或从资源库换人）；上面泰语示例里的名字请以当前项目人物为准。
- 中文项目不要混进泰语句子，泰语项目不要混进中文句子；两种语言要混用就把项目切成「双语」。
- 双语项目改一栏**不会自动覆盖另一栏**，页面会给出「保持独立 / 用中文覆盖泰文 / 用泰文覆盖中文」的显式选择。

## 7. 常见错误

| 错误写法 | 后果 | 改法 |
| --- | --- | --- |
| 整段小说，没有分行 | 只切成 1～2 个超长镜头 | 一行一句 |
| 只写台词不写人物名 | 分镜随机分配说话人 | 加人物名 |
| 一句三四十个字 | 字幕溢出、配音过长 | 拆成两句 |
| 泰语逐字翻译中文 | 台词生硬 | 换成日常口语句式 |
| 单语项目里混写另一种语言 | 该语种的字幕/配音里会混进外语 | 切换语言类型或分行整理 |

## 8. 从文案到镜头的流程

1. 在「剧本编辑」页选输入方式：`只填主题，本地模板生成` / `粘贴中文文案` / `粘贴泰语文案` / `导入已有剧本`。**当前文本引擎是本地规则模板，离线、无需密钥，未接在线 AI**；主题只给内置句式排序、写标题与开场白、台词没命中时兜底选场景，不会创作剧情。
2. 粘贴符合上面规范的文案（或填主题用内置句式），点「③ 生成剧本」。粘贴模式一律按规范逐行解析，不判别风格。
3. 生成结果：**中文正文框保留你写的规范原文**，下方「对白行」是它的结构化视图。人物对白每行四列（双语项目再加泰语对白列）；情境 / 旁白行单独标出，只保留可编辑的描述内容。场景行只提场景名，不生成行。
4. 逐行校对：说话人下拉**只能选项目里真实存在的人物**（或「未指定」）——旁白不是人，不在下拉里；情绪、动作可下拉选常用词，也能直接打字自己填。改任一行会**按规范重建并写回中文正文对应行**；反过来改了正文框，点「重新解析正文」把改动同步回对白行。泰语正文保持独立编辑。
5. 点页面顶部「提交并自动分镜」→ 按行逐行切镜，说话人、情绪、动作、场景都取对白行的值并估算时长；情境 / 旁白行生成无出场人物的画外音镜头，字幕不署名。

> 场景由台词关键词 + 场景行提取的场景名共同决定；两样都没命中时才在通用场景池里轮换。改了场景关键词不会回溯已有镜头，需重新提交分镜。
